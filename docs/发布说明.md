# 发布说明

发布范围：Helium10、链接找同类竞品、图片找同类竞品，以及必要的 VPS 采集依赖，共 4 个 Skill。其余 Skill 不属于本公开包。

## 公开副本处理

- 去除私人 VPS 默认地址，改为使用者显式提供自己的 HTTPS 服务地址；地址配置无效时停止。
- 将特定用户的 Runner 路径替换为通用安装路径示例，说明外部 Runner 仍需适配。
- 将原部署项目的容器和外部网络名称通用化。
- 将无公开来源说明的供应商产品案例替换为明确虚构示例。
- 不包含账户凭据、代理密码、运行日志、原始研究结果或私人仓库的 Git 历史。

这些调整只针对公开副本；不代表原安装环境已升级，也没有修改其他私人 Skill。

## 验证与限制

Helium10 的 15 项离线测试通过；新增 VPS 配置安全测试 4 项通过，覆盖缺少 URL、非 HTTPS/带身份的 URL、显式配置和缺少令牌。测试不访问网络、不读取真实账户，也不调用实际采集。

源码公开可审阅，不代表所有业务路径已运行。Helium10 与 SellerSprite 真实查询、Docker 部署、代理连接和外部 Runner 端到端行为尚未验证。现有方法和平台结构可能变化，实际执行时应核验。

发布采用独立仓库、全新提交历史，并核对暂存文件和 manifest。后续正常变更通过新增提交进行；源码可用回退提交恢复。公开后的内容可能被下载或复制，改回私有不能撤销已经发生的外部复制。
