# 配置说明

| 入口 | 必要 Skill | 外部能力 |

| Helium10 关键词调研 | 自身 | Helium10 插件、Python、openpyxl |

插件和 MCP 由使用者自行安装、授权，不随源码复制。SellerSprite 缺失时不能声称完成销量覆盖和父子体证据校验。

## VPS 客户端

必须设置 `AMAZON_SCRAPER_VPS_URL` 为自己服务的 HTTPS 基础地址，例如 `https://scraper.example.com/amazon-scraper`。这个地址只是示例，不能直接使用。公开客户端没有默认私人服务器；缺少地址或使用不安全的地址时，在发请求前停止。

公开版仅支持显式 HTTPS API：不会读取私人 SSH 配置，也不提供 loopback HTTP 例外。缺少或无效地址会在读取保存的凭据之前停止。私有源码里的 SSH 传输不是本公开包的功能，不要将私人机器配置放进此目录。

客户端从 `AMAZON_SCRAPER_VPS_TOKEN` 或本机 Windows Credential Manager 的 `Codex/AmazonScraperVPS` 条目读取令牌。不要把令牌写进 URL、源码、报告或 Git。

服务端素材在 `skills/amazon-scraper-vps/assets/service/`。需要使用者自行部署 Docker 服务并提供 HTTPS 反向代理；内部服务端口为 8790。服务端认证变量为 `EXTRACTOR_API_TOKEN`，代理变量按实际服务代码配置为 `AMAZON_PROXY` 或 `AMAZON_PROXIES`。客户端令牌必须与自己的服务端配置匹配。

`compose.yml` 引用由使用者自行准备的外部网络 `amazon-scraper-network`，并读取本地 `.env`；仓库不附真实 `.env`。`config/proxies.json` 保持空数组，代理凭据只保存在部署环境。不要把源码公开理解成已部署、免费或共享的服务。

健康检查必须同时为 `status: ok` 和 `proxy_configured: true`，否则停止采集，不能退回本机直接访问 Amazon。

每次采集或图片下载前重新检查健康状态；只接受 HTTPS Amazon 美国站页面、1–5 页，以及允许的 Amazon 图片域名。失败状态不会伪装成功，错误正文不回显代理身份。保存图片前检查大小、类型和文件签名；实际业务验收仍须完整解码并查看图片。

## 外部 Runner

两个竞品 Skill 保留了严格的任务身份、命令、图片与覆盖证据契约。文档命令使用 `/opt/codex/skills` 作为通用安装根示例。使用者必须让 Runner 的安装路径、命令白名单和证据核验一致；不能只改一条命令就声称完成适配。

仓库不含该 Runner。当前搜索与下载辅助脚本不能单独完成文档要求的所有 digest 绑定和独立视觉验证。缺少这些证据时应标记部分完成或阻塞，不能绕过校验。

## 已知旧配置限制

服务子包 `package.json` 中旧的 `test`、`setup` 命令引用了本包未提供的文件，不应作为本公开包的安装或测试入口。实际服务入口是 `server.js`；本仓库的离线验证采用 Python unittest 和 JavaScript 语法检查，未执行部署。
