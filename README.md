# 工作台精选 Skill

面向关键词调研和玩具同类竞品研究的公开源码。这里仅发布 **3 个工具入口和 1 个必要依赖**，不包含其他业务或私人 Skill。

## 先选工具

| 工具 | 你提供什么 | 主要产物 |
| --- | --- | --- |
| [Helium 10 关键词调研](skills/helium10-keyword-research-v1-1-0/SKILL.md) | 同一站点的 2–5 个 ASIN、站点、明确的变体口径 | 关键词汇总 Excel 和校验收据 |
| [链接找同类竞品](skills/find-toy-lookalike-competitors/SKILL.md) | 美国站玩具链接或 ASIN、研究深度与数据月份 | 按外观分层的竞品清单、图片对照和证据材料 |
| [图片找同类竞品](skills/find-toy-lookalikes-from-product-image/SKILL.md) | 产品图、包装图或供应商资料图 | 产品特征说明、三层同类竞品市场和资料缺口 |
| [VPS Amazon 采集依赖](skills/amazon-scraper-vps/SKILL.md) | 自己部署的服务、代理和授权配置 | 给两个竞品工具提供页面数据和图片 |

Helium10 用于比较关键词。链接工具从已有商品出发；图片工具从原图出发。两个竞品工具专注于玩具外观相似度，不是任意品类的通用以图搜图服务。

## 使用前先看这一段

这是 Skill 方法、脚本和配置样例的源码仓库。**公开源码不包含插件账号、查询额度、代理账号、托管采集服务或工作台执行后台。**

- Helium10 需要你自己的插件连接，以及 Python 和 `openpyxl`。现有离线测试已覆盖关键词合并、过滤、表格和收据。
- 两个竞品工具需要自己的 VPS 服务、SellerSprite MCP 和图像查看能力。完整流程还依赖外部 Runner 提供任务身份、隔离视觉审查、命令及证据校验；**这个 Runner 没有包含在仓库中，完整竞品流程尚未做端到端验证。**
- 当前关键词 Excel 固定为每个 ASIN 保留自然排名和广告排名两列；广告数据缺失时留空。关键词是否保留只看自然排名是否至少一次进入 1–24。

## 怎样开始

1. 打开对应 `SKILL.md`，看输入要求、边界和产物。
2. 将需要的完整 Skill 文件夹放到当前 Codex 实例识别的技能目录，保留脚本和参考文件。已有同名目录时先比较和备份。
3. 使用两个竞品工具时，同时保留 `find-toy-lookalike-competitors` 与 `amazon-scraper-vps`；图片版还需要链接版的流程。
4. 按 [配置说明](docs/配置说明.md) 配置你自己的服务和授权，然后再提供真实任务输入。

### Helium10 示例

```text
使用 $helium10-keyword-research-v1-1-0
ASIN：<第一个真实 ASIN>、<第二个真实 ASIN>
站点：US
变体口径：仅精准 ASIN
请生成关键词汇总 Excel 和收据。
```

### 链接或图片找竞品

```text
使用 $find-toy-lookalike-competitors
目标：<美国站玩具链接或 ASIN>
数据月份：<YYYY-MM>
按真实图片区分核心、扩展、外围市场，注明覆盖和销量证据限制。
```

没有商品链接时，改用 `$find-toy-lookalikes-from-product-image` 并附原始产品图片。缺少工具、授权或证据时，应明确报告缺失项，不能伪造完整结果。
