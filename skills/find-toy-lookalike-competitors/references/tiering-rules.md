# Three-tier visual market rules

Use the target image as the visual anchor. Judge the main product, not packaging graphics, children, props, or duplicated pieces arranged for advertising.

## Decision dimensions

Evaluate in this order:

1. Primary silhouette: overall body outline and proportions.
2. Main structure: openings, storage, attachment, transformation, carrier, shell, or limb layout.
3. Product composition: piece count, parent-child arrangement, and relative scale.
4. Theme and details: vehicle type, animal, character, color, accessories, and interaction.

Silhouette and main structure outweigh color and title wording.

## Tier 1 — 核心外观市场

Require both:

- closely matching primary silhouette;
- closely matching main structure.

Also require the same product theme and broadly comparable composition. Allow small differences in color, decoration, accessory shape, or exact piece count when the main product presentation remains substantially the same.

Use Tier 1 for direct price, sales, rating, and listing comparisons.

## Tier 2 — 扩展外观市场

Use when the same design direction remains recognizable but one material dimension changes:

- same or closely related shell with a different theme;
- same mother-product structure with a noticeably different piece count;
- same silhouette with a modified opening, tier, roof, trailer, or attachment;
- a parent/variation family whose child product crosses the Tier 1 boundary.

Use Tier 2 to understand substitutes, design extensions, and family expansion. Do not silently merge it into Tier 1.

## Tier 3 — 外围结构市场

Use when the broad physical concept is shared but the principal silhouette or structure differs. Examples include:

- a shelf-style semi carrier versus an integrated windowed carrier;
- a flatbed trailer versus an enclosed storage body;
- a multi-level ramp versus a single-body carrier;
- a large multi-piece construction set versus a compact mother-and-child set.

Use Tier 3 for market context, high-sales coverage, price ceilings, and alternate design directions. It is not the direct exterior market.

## Excluded

Exclude products that only share a need, age group, keyword, theme, or Amazon category. Examples: standalone construction vehicles, unrelated truck sets, play mats without a comparable main body, ride-ons, building sets, remote-control products, and accessories.

## Tie breakers

- If only the color differs, keep the original tier.
- If the same mold changes theme, prefer Tier 2 unless theme is visually minor.
- If piece count changes but the hero product remains visually dominant and comparable, use Tier 1 or Tier 2 according to how much the main image composition changes.
- If a high-sales product is visually different, keep it in Tier 3 or Excluded and explain why.
- If uncertain between adjacent tiers, choose the broader tier and ask the user one concrete visual-boundary question.

## Tested examples

- Quadruped robot dogs: body architecture and leg layout dominate generic “programmable robot” wording.
- Animal press-and-go cars: animal face/body treatment and vehicle silhouette dominate the shared toddler play need.
- Construction carrier trucks: integrated short-cab body, side openings, and mini-vehicle arrangement distinguish Tier 1 from shelf semis and flatbeds.
